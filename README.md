# Housemait

A modern, responsive family organizer website designed to bring everyday family activities together in one place.

## Features

- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile screens.
- **Dark Mode:** Switch between light and dark themes.
- **Interactive Features Section:** Explore different family organization features, including:
  - Calendar
  - Chores
  - Meals
  - Lists
  - Health
  - Documents
  - WhatsApp
- **School Letters:** A dedicated section for organizing school-related information.
- **Family Assistant:** UI showcasing ways to handle family administration through photos, voice notes, and forwarded emails.
- **Child Mode:** A child-friendly interface featuring quests and rewards.
- **Reviews:** A testimonials section with a scrolling review slider.
- **Privacy Section:** Highlights the product's privacy-focused approach.
- **Pricing Plans:** A section presenting subscription information.
- **FAQ:** Frequently asked questions.
- **Scroll Reveal Animations:** CSS-based animations that reveal elements while scrolling.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- CSS Custom Properties (Variables)
- CSS Animations
- CSS Scroll-Driven Animations
- Font Awesome
- Google Fonts / Custom Fonts

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/gamalshamy/Housemait.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Housemait
   ```

3. Open `index.html` in your browser.

   You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## Design & Development

The project focuses on clean UI design, reusable CSS styles, responsive layouts, and smooth animations to create a pleasant browsing experience.
